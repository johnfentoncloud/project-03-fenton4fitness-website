# F4F Apparel source artwork

Place the approved, original high-resolution artwork in this local-only folder:

- `f4f-left-chest-logo.png`
- `f4f-good-better-best-back.png`

The artwork files are ignored by Git and must not be committed. Preserve these
originals without resizing or overwriting them. Create separate optimized web
previews in `website-files/images/apparel/` after both approved files are
available and visually verified.
